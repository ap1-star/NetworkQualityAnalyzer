How the live feed works

  1. A scheduled GitHub Actions workflow checks the official source URLs every six hours, when the workflow is enabled and GitHub runs it.
  2. The crawler extracts links matching recruitment-related words and writes a timestamped JSON feed.
  3. The dashboard fetches the latest published JSON when opened and when you press “Check feed”.
  4. A “new” badge means a URL was newly discovered after the baseline crawl, not that a job is newly announced or that applications are open.
  5. Source errors are recorded. Dynamic pages, PDFs without HTML links, CAPTCHAs, robots restrictions and separately hosted notices can be missed.
Eligibility and deadlines are not automatically certified. A GATE keyword match is only a search hint, not proof that a specific role accepts GATE EC. Check the detailed official advertisement for branch, age, minimum marks, category, dates, fees and selection process.

The current version stores shortlist, progress and checklist in browser local storage; it does not sync across devices or send push/email alerts by itself.
